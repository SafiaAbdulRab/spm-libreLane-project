# SPM – Digital IC Design Project

## Project Overview

A digital IC design project implemented using LibreLane in an Ubuntu environment. The project focused on the RTL-to-GDSII design flow and practical VLSI implementation.

## Tools Used

- Ubuntu Linux
- LibreLane
- Verilog
- Digital IC Design Tools

## Work Performed

- RTL design and preparation
- Logic synthesis
- Physical design flow
- Floorplanning
- Placement and routing
- GDSII generation
- Design analysis and verification

## Project Output

The project demonstrates the practical implementation of a digital design through the RTL-to-GDSII flow using an open-source VLSI design environment.
